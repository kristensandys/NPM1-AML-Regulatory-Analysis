# Example input

This directory contains one DESeq2 differential H3K27ac
peak-results table.

- Comparison: NPM1.1 vs NPM1.2 
- Genome build: GRCh38
- Data type: ChIP-seq research data 
- Coverage: subset

This file illustrates the expected input format. The full
cross-group analysis requires the remaining comparison files.

To use this input, place it in the matching comparison's
`01_deseq2/` directory, following the workflow documentation.
