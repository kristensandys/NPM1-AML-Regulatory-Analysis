# H3K27ac differential-peak analysis workflow used in my thesis

This directory contains the production scripts and analysis results used for the H3K27ac differential-peak component of the thesis. 
The workflow was run independently of ANANSE. Candidate genes were defined by GREAT association within 3 kb of a transcription start site (TSS).

The separate `test` directory located one level above this project was used to test individual stages on representative input data. Test outputs are not production thesis results.

## Input data

The workflow uses differential H3K27ac ChIP-seq results generated with DESeq2. Each `.diffexp.tsv` file is stored in the relevant comparison's `01_deseq2` directory.

The following supporting RNA-seq files are stored in the project root:

```text
rnaseq_metadata.xlsx
GRCh38-TPM.tsv
```

The project contains separate analysis directories for:

```text
59_NPM1.1_differential_peak_project

64_NPM1.4_differential_peak_project
65_NPM1.3_differential_peak_project

```

The NPM1.5-versus-NPM1.4 DESeq2 result was not previosuly generated by seq2science DESeq2.

## Analysis workflow

### 1.  select differential peaks by ranked 100 regions 


## run script: 
```r
source("~/Desktop/H3K27ac_diff_peak/h3k27ac_differential_peak_analysis/scripts/01_extract_top_100_regions_batch.R")
```

This script:
1. Read the DESeq2 differential-peak table.
2. Removed rows with a missing `log2FoldChange` value.
3. Oriented the fold change to the target NPM1 subtype named first in the comparison directory.
4. Separated peaks into upregulated and downregulated directions.
5. Ranked upregulated peaks from the largest positive fold change downwards.
6. Ranked downregulated peaks from the most negative fold change upwards.
7. Selected up to 100 observations in each direction. The table header was not counted as an observation.
8. Wrote the selected peak tables to the comparison's `02_top_regions` directory.
9. Wrote peak summary counts to the subtype project's `summary` directory.

## 3. Extract genes and retain the closest transcription start site (TSS) association

This stage extracted the GREAT-associated genes from all GREAT mapping files. 
If the same gene was associated with multiple peaks, only the association with the shortest
absolute peak-to-TSS distance was kept. The final gene tables were ordered
alphabetically to make manual inspection easier.

Run the script and set the working directory:

```r
setwd("~/Desktop/H3K27ac_diff_peak/h3k27ac_differential_peak_analysis/scripts/")
source("03_extract_genes_with_tss_distance_batch.R")
```

The script processed all 36 GREAT mapping files. It generated 
1. a `.tsv` table containing each unique gene, its signed TSS distance, and
   its absolute TSS distance.
2. a `.txt` file containing the gene names only.

The output files were written to each comparison's:

```text
03_great/cleaned/
```
