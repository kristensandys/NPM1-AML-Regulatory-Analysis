# NPM1-AML-Regulatory-Analysis
Analysis of transcriptional and epigenomic differences between NPM1-mutated AML subtypes using RNA-seq, ChIP-seq, ANANSE, and R.

RNA-seq and ChIP-seq preprocessing was performed using the established seq2science workflow. 
The scripts in this repository focus on downstream data processing, differential peak analysis, integration of GREAT and ANANSE outputs, pathway enrichment, and visualisation, developed as part of my MSc research project.
